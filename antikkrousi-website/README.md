# Ψηφιακή έκδοση

Ανοίξτε το `index.html` σε σύγχρονο browser. Η ιστοσελίδα λειτουργεί τοπικά χωρίς εξωτερικές γραμματοσειρές ή βιβλιοθήκες.

Περιλαμβάνει τις 59 σελίδες, 29 εικόνες, τις τοπικές γραμματοσειρές του PDF, έμφαση, χρώματα, υπογραμμίσεις και συνδέσμους. Το κείμενο υπάρχει ολόκληρο στο HTML και διαβάζεται χωρίς JavaScript. Το JavaScript προσθέτει αναζήτηση και ρύθμιση μεγέθους γραμμάτων.

Η ορθογραφία ακολουθεί το PDF: τα μονοτονικά παραθέματα παραμένουν μονοτονικά. Οι επαναλαμβανόμενες κεφαλίδες και οι έντυποι αριθμοί σελίδας αντικαθίστανται από πλοήγηση HTML. Οι συλλαβισμοί στο εσωτερικό παραγράφων αποδίδονται με soft hyphen. Η διάταξη προσαρμόζεται στην οθόνη και δεν είναι φωτογραφική αναπαραγωγή της σελιδοποίησης του PDF. Κάθε σελίδα συνδέεται με το αντίστοιχο πρωτότυπο.

Το `index.previous.html` είναι αντίγραφο της προηγούμενης ιστοσελίδας.
Το `verification.json` καταγράφει τον έλεγχο πληρότητας και τον περιορισμό του οπτικού ελέγχου.

Αναδημιουργία από το αμετάβλητο `assets/original.pdf` (Python με PyMuPDF):

```
python3 tools/build_from_pdf.py
```

Τα `assets/style.css` και `assets/reader.js` διατηρούνται ανεξάρτητα από την αναδημιουργία.
